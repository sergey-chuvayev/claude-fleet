## Design Context

### Users
A local operator monitoring their Claude Code sessions, identifying work that needs attention and reconnecting tasks with code reviews and tickets.

### Brand Personality
Serious, polished, precise. The user explicitly requested improved visibility, charts, status, latest responses, PR and Linear links, and a fancy dark UI.

### Aesthetic Direction
A minimalist, conversation-first dark workspace inspired by the user's Grok Bot
reference (October 1, 2026). Use neutral charcoal surfaces, warm white prose,
compact agent avatars and subtle status colors. A narrow session sidebar, spacious
conversation and collapsible right inspector form the desktop layout. Keep
monospace for code and tool output, with completed tools tucked into disclosures.

### Design Principles
- Prioritize actionable session state and context pressure.
- Show real local data and distinguish recorded links from live integrations.
- Keep monitoring read-only; use the official Claude Agent SDK for explicitly managed sessions, with visible tool approvals and no permission bypass.
- Support keyboard navigation, small screens and reduced motion.
- Keep the workspace palette neutral and consistent, independent of the terminal theme.
